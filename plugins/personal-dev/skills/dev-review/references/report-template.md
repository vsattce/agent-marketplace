# 增强代码审查报告

报告按实际审查规模组织以下内容；小范围审查可用短段落，无需为每个维度创建表格或填写不适用项。

## 状态与范围

给出 `COMPLETE`、`PARTIAL` 或 `BLOCKED`，记录项目、检查范围、源码/工作区基线、实际覆盖和遗漏。无发现时明确说明；有代码变化时说明受影响的证据是否重新核实。

## 审查配置

记录实际 Harness 与已校验 reviewer 的型号、强度。发生独立复核时记下复核结论；额外提供 worker 时才记录它，不要求识别主模型身份或逐一登记代理元数据。

## 发现

按 P0–P3 排序。每项给出等级、证据状态、代码位置、触发条件、影响、证据和建议；P0/P1 附独立复核结论，P2 简述，P3 合并同类项。

## 限制与交付

列出未完成的检查、待运行验证及所需条件，状态为 BLOCKED 时说明继续所需的信息。记录报告保存路径；无法落盘时在聊天输出并说明。路径、ID 和防覆盖规则见入口。
