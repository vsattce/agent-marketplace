# 审查子代理模型与思考强度契约

本契约只服务 `dev-review`；主会话模型与强度不变。

## 显式参数与入口校验

必填本次显式 `reviewer=<model>:<effort>`，别名为 `reviewer / review / r / check`，不区分大小写。角色与值可用 `=`、`:` 或空白分隔，model 与 effort 可用冒号或空白分隔，例如 `r 6.1terra high`、`r=6.1terra:HIGH`。

每项恰好一次，model / effort 非空。缺项、重复（含别名）、额外值、非法或歧义参数立即 BLOCKED。参数只从本次调用提取，不从示例、历史或默认配置补值。入口在读取源码、创建报告和派发前校验。兼容显式额外提供的 worker（worker / work / w / code），提供时同样校验；不会因此派发执行代理或扩大只读权限。

## 当前 Harness 校验

顺序为：解析参数 → 归一化 → 与本轮实际子代理模型清单唯一匹配 → 校验该型号的 effort → 展示精确配置并执行。

- 模型忽略大小写，完整数字版本与系列名可省略 gpt 前缀及常见连字符；`6.1terra / 6.1-terra / gpt6.1terra / gpt-6.1-terra` 同键。保留小数点与完整系列名；其他原生 ID 仅忽略大小写，不模糊匹配或补版本。
- 请求必须恰好命中一个实际 ID，零命中或重名均 BLOCKED，不以价格、代际或 effort 挑选型号。
- effort 忽略大小写，支持 `h → high`、`m → medium`；必须匹配该型号实际支持的值，不推断缺项、不替换配置。

reviewer 单参数无需 worker 型号或执行能力。缺少本轮名单、支持证据、独立上下文或实际覆写能力，型号不可用或 effort 不支持时立即 BLOCKED。不 fallback、不继承原生默认，不修改全局设置或嵌套客户端补能力。原生拒绝或返回配置不一致时停止并报告，不换配置重试。

Codex 协议见 [Codex adapter](codex.md#模型校验与显示)，其他 Harness 依照其原生 schema 校验。成功后只展示已提供角色的 `<角色> 模型：<实际 ID>｜思考强度：<effort>`，不再确认。

## 审查与复核

全部审查、符合性检查、验证证据核查与按需独立复核使用同一 reviewer 配置。审查代理只读、不修复、不提交、不派生代理。普通审查默认一个 reviewer；严重或争议发现按主 Skill 定向复核，不附加开发修复轮次或重复全量验证。

恢复时核对本次显式配置与已有代理状态，不一致或无法核验时停止续接并说明。
