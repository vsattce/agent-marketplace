# Domain Docs

本仓库采用 single-context 领域文档布局。

## 读取规则

探索代码库前，读取根目录的 `GLOSSARY.md`，以及 `docs/adr/` 中与当前任务相关的架构决策。

文件不存在时直接继续，不为完成初始化创建空文件。
需要整理术语或记录已确定的决策时，由 `domain-modeling` 按任务范围维护。

## 文件布局

- `GLOSSARY.md`：全仓库共享的领域术语。
- `docs/adr/`：架构决策记录。

## 使用规则

Issue、设计、代码和测试中的领域概念沿用术语表定义的名称。
发现术语缺口时，在相关领域建模工作中处理。

方案与已有 ADR 冲突时，明确指出对应决策、冲突内容和重新评估的原因。
